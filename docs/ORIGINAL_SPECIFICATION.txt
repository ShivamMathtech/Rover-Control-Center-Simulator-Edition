You are a senior robotics software architect, full-stack engineer, UI/UX designer,
computer-vision engineer, ROS engineer, embedded-systems engineer, and DevOps engineer.

I want you to build a production-quality FULL-STACK CONTROL SOFTWARE for a
4-wheel autonomous surveillance rover.

The rover is a non-weaponized mobile robotics platform intended for lawful
monitoring, inspection, navigation, mapping, research, and security/safety
applications.

DO NOT implement weapon control, targeting, firing, harmful payloads, or
offensive capabilities.

===========================================================
1. PROJECT OBJECTIVE
===========================================================

Build a professional Ground Control Station (GCS) / Rover Control Center that
allows an operator to:

1. Monitor the rover in real time.
2. View multiple live cameras simultaneously.
3. Control the rover manually.
4. Switch between MANUAL, ASSISTED and AUTONOMOUS modes.
5. Plan and execute waypoint missions.
6. Display the rover on a live map.
7. Display GPS/RTK position and heading.
8. Monitor all available rover sensors.
9. Display battery and electrical telemetry.
10. Display motor and hardware health.
11. Display AI/computer-vision detections.
12. Detect and visualize obstacles.
13. Record telemetry and video metadata.
14. Maintain mission history.
15. Provide emergency-stop and fail-safe behavior.
16. Provide a complete diagnostics interface.
17. Operate even when some sensors/cameras are unavailable.
18. Clearly distinguish simulated data from real hardware data.

The software must be modular so that the simulator can be replaced by real
hardware drivers without rewriting the frontend.
